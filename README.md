## C Programs

The C programs can be compiled using **GCC / MinGW**.

```bash
gcc Q1.c -o Q1
```

Run on Windows:

```powershell
.\Q1.exe
```

The C++ programs can be compiled using **G++ / MinGW**.


This repository is primarily maintained for my **college laboratory assignments**.

Suggestions, corrections, optimizations and improvements are welcome.

### How to Contribute

1. Fork this repository.
2. Create a new branch.

```bash
git checkout -b feature/improvement
```

3. Make your changes.
4. Test your program.
5. Add and commit your changes.

```bash
git add .
git commit -m "Improve assignment program"
```

6. Push your branch.

```bash
git push origin feature/improvement
```

7. Create a **Pull Request**.

### Contribution Guidelines

* Keep the existing assignment structure.
* Keep each question in its respective `Q1`, `Q2`, etc. file.
* Use meaningful variable and function names.
* Test programs before submitting changes.
* Add comments where necessary.
* Do not remove existing assignment solutions without a valid reason.
