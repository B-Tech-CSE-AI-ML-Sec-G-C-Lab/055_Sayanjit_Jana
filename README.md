## 📝 Assignment Questions

### Q1. Check Prime Number

Checks whether a given number is a **prime number** using a function and loop.

**Concepts used:**

* Functions
* `for` loop
* Conditional statements
* Modulus operator

### Q2. Prime Numbers in a Given Range

Finds and displays all prime numbers between a given starting and ending number.

**Concepts used:**

* Functions
* Loops
* Conditional statements
* Range-based iteration

### Q3. Armstrong Number

Checks whether a given number is an **Armstrong number**.

**Concepts used:**

* Functions
* `while` loop
* Arithmetic operations
* Digit extraction

### Q4. Reverse and Palindrome Check

Checks whether a given number is a **palindrome** by reversing the number and comparing it with the original number.

**Concepts used:**

* Functions
* `while` loop
* Number reversal
* Conditional statements

### Q5. Fibonacci Series

Generates the Fibonacci series for a given number of terms using a function.

**Concepts used:**

* Functions
* Recursion
* `for` loop
* Mathematical sequences

### Q6. Count Even and Odd Numbers

Counts the number of even and odd numbers from `1` to `N`.

**Concepts used:**

* Functions
* Conditional logic
* Integer arithmetic
* Input validation

### Q7. Menu-Driven Calculator

Implements a menu-driven calculator supporting:

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit

**Concepts used:**

* Functions
* `switch-case`
* Loops
* Input handling
* Error handling for division by zero

## ▶️ How to Run

Make sure a C compiler such as **GCC** is installed on your system.

Navigate to the assignment directory and compile any program:

```bash
gcc Q1.c -o Q1
```

Run the compiled program:

```bash
./Q1
```

For Windows:

```bash
Q1.exe
```

You can similarly compile and run `Q2.c` through `Q7.c`.
